
A fun and interactive game built with Pygame where players dodge falling blocks, solve math problems, and customize their avatar. The game features multiple modes including gameplay, question management, and customization options.

Features

Start Screen & Name Input: Enter your name at the beginning to personalize your experience.
Gameplay Mode:
Dodge falling blocks of varying effects (+HP, -HP, or +score).
Solve generated math problems to earn points.
Visual HUD displaying HP, Score, Timer, and current question.

Code Structure

game.py: Main game script containing all game logic.
Game States: Manage different screens like start menu, gameplay, question input, and game over.
Classes: Button class for UI buttons.
Variables: Track player status, blocks, questions, scores, and customization settings.
